04 — Four-agent runtime on local Ollama

You asked for AI agents in day-to-day work. This is not a chatbot screenshot.

On my lab machine I run four agents as four separate Python processes, each with its own virtual environment and tool loop, orchestrated against local Ollama on an RTX 4070 under WSL2. If one agent crashes or writes a bad script, the other three keep running. They do not chat in free text. They hand off structured JSON contracts. Page 12 of the PDF walks the architecture. This is the same self-heal loop I use when I bench GPUs in Local Grid Suite.

01 Systems

Names the constraints and interfaces: what already exists, what must not break, what “done” means. Same job as the cover of an Environment Summary — owner, date, utilization first, what is still on fire.

02 Architect

Turns that into a Pydantic contract — a JSON schema the next agent can consume without guessing. No prose handshake. A schema is a contract on a bank floor and on a GPU.

03 Synthesis

Generates the payload against local Ollama. The work happens on this machine, the same way a POC happens on the customer’s metal instead of a vendor VM they will never buy from.

04 Validator

Checks schema and graph. If it fails, it writes, executes, and debugs Python through the local LLM until the contract passes. Isolation plus a self-heal loop. Not “I played with agents.”
